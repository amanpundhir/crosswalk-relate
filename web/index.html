How it works in 3 steps

  1. 1. Your question

    You ask Crosswalk, for example: is MFA covered for the 800-171 audit?

  2. 2. Cited graph paths

    The agent answers, and each claim cites a path: requirement, control, evidence.

  3. 3. The claim checker

    The checker re-runs each path and drops any claim that fails. People approve every change.

The claim checker on a real question

The agent first says MFA is covered. The checker finds the evidence expired on 1 December and the second mapping is only proposed. The answer you see is corrected.
